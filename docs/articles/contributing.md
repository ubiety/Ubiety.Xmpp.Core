# Contributing

Thank you for your interest in contributing to Ubiety.Xmpp.Core!

## How to Contribute

- Fork the repository and create your branch from `develop`.
- Follow the .NET coding conventions and project guidelines.
- Write unit and integration tests for your changes.
- Submit a pull request with a clear description of your changes.

## Code of Conduct

Please be respectful and follow the project's code of conduct in all interactions.
